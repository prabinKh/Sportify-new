Step-by-Step Flow

What happens when users join a jam room

1

👑 Host Creates Room

Any logged-in user creates a jam room. A unique 6-character code is generated. Latest downloaded song auto-loads.

2

🔗 Share Invite

Host clicks "Invite Friends" → copies room code or a direct link. Friends paste the link or enter the code.

3

🎯 Instant Sync on Join

When listener's audio loads, app fetches live server position (pos + elapsed time) and seeks to exactly that point.

4

🔄 Continuous Sync

Every 2 seconds, listeners poll the server. If drift > 2s, audio hard-seeks back. Play/pause is auto-enforced.

5

🔒 Host-Only Controls

Only the host can play, pause, seek, or change tracks. Listeners are blocked at UI level AND via native audio event guards.

6

🚪 Leave → Full Access

When a listener leaves the room, they return to the normal player with all controls restored immediately.

Access Rules

Who can do what inside a jam room

👑

Host Controls

✅ Play / Pause
✅ Seek scrubber
✅ Change track
✅ End / Delete room
✅ Volume (local)
✅ Live chat

🎧

Listener View

❌ Play / Pause (locked)
❌ Seek (disabled)
❌ Change track (hidden)
✅ Volume (local only)
✅ Live chat
✅ Leave anytime

⚡

Sync Mechanism

🔄 Poll every 2 seconds
📍 livePos = pos + elapsed
🎯 Drift > 2s → hard seek
🎵 Track change → hot-swap
🚪 Leave → full controls

🔗

Invite Flow

1. Click "Invite Friends"
2. Copy code or link
3. Friend opens link
4. Enters code → joined
5. Auto-syncs 🎉
